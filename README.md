# Main Sewer Line Inspection and Repair Guide

A homeowner workbook for ordering and reading a sewer-scope camera video, diagnosing tree-root intrusion and bellied pipes, comparing trenchless CIPP lining against open-trench excavation, and calling 811 before digging, citing US EPA and 811.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — main sewer lateral inspection and ownership basics: `https://ahmetalkan.github.io/main-sewer-line-inspection-and-repair-guide/`
- Subpage — warning signs of main-line trouble and ordering a proper camera scope: `https://ahmetalkan.github.io/main-sewer-line-inspection-and-repair-guide/camera-inspection-and-warning-signs.html`
- Subpage — understanding tree-root intrusion and negative-slope pipe bellies: `https://ahmetalkan.github.io/main-sewer-line-inspection-and-repair-guide/tree-roots-and-bellied-pipes.html`
- Subpage — comparing CIPP lining, pipe bursting, and open-trench replacement: `https://ahmetalkan.github.io/main-sewer-line-inspection-and-repair-guide/trenchless-lining-vs-excavation.html`

It cites public pages on [sewerlinelabs.com](https://sewerlinelabs.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
